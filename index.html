Pasos para reservar

  1. Seleccionar el albergue y la modalidad:

    • Reservar alojamiento: estadía con cama reservada
  2. Completar el formulario en línea con todos los datos solicitados y obtener el código de pre-reserva.
  3. Subir comprobante de pago para confirmar la reserva.
